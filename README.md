## Project Description

This project is a Full Stack Blog Application developed using the MERN Stack (MongoDB, Express.js, React.js, Node.js). It provides secure user authentication and allows users to create, edit, delete, and manage blog posts.

## Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication
- HTML
- CSS
- JavaScript

## Features

- User Registration
- User Login & Authentication
- Create Blog Posts
- Edit Blog Posts
- Delete Blog Posts
- Responsive User Interface
